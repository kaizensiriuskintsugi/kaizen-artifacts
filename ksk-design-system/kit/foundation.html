The laws — enforceable, countable
  1. One fill per pane. Count filled gold elements on any surface: the answer is always 0 or 1.
  2. Seam is a line, never a fill. Identity lives in hairlines, seams, focus rings, edges.
  3. Ember is earned. Heat marks genuine urgency or live activity — never decoration.
  4. Body text is never gold. Gold text only as uppercase micro-labels or emphasis inside display copy.
  5. Serif never below 20px, never in UI chrome. No serif buttons, labels, cells, meta, or forms.
  6. Dark-first, dark-only. There is no light mode.
